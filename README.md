# nhan-dang-cu-chi-tay
Sử dụng MediaPipe kết hợp OpenCV để phát hiện các khớp bàn tay theo thời gian thực. Ánh xạ tọa độ ngón tay để điều khiển chuột máy tính và thực hiện các thao tác (click, scroll, drag)
